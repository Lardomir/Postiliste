# Abnahmecheckliste – M324 Poschtilischte

## Funktionen

- [ ] Login, falsche Zugangsdaten, Logout
- [ ] Admin kann Benutzer erstellen, bearbeiten, löschen
- [ ] User darf /admin/users auch als direkte URL nicht öffnen
- [ ] Benutzer A sieht nur eigene/zugewiesene Listen
- [ ] Admin sieht und bearbeitet sämtliche Listen
- [ ] Listentitel, optionales Datum, Verantwortliche, User-Zuweisung, erledigt/offen
- [ ] Listen erstellen/bearbeiten/löschen
- [ ] Artikelname, optionale Menge, gekauft/offen und löschen
- [ ] Responsive Bedienung am Smartphone
- [ ] Zuweisungs-/Änderungsnachrichten in smtp4dev

## DevOps / Kompetenznachweis

- [ ] GitHub Projektboard: Status, Priorität, Deadline, Verantwortliche
- [ ] Granulare Issues mit DoD und passenden Commits
- [ ] ESLint, Prettier, Husky und npm-Scripts laufen
- [ ] Unit-Test (konstruktiv/destruktiv/Grenzwert) läuft
- [ ] Integrationstest speichert über HTTP bis in echte Test-DB
- [ ] Docker-Produktionsimage startet
- [ ] PostgreSQL-Daten überleben Container-Neustart
- [ ] Jenkins läuft und führt Tests innerhalb des Testimages aus
- [ ] Jenkins baut das Produktivimage und startet Compose
- [ ] README: Developer, Tester, CI, Architektur, Release
- [ ] PR wird unabhängig reviewed/approved
- [ ] main enthält freigegebenen Stand; Versions-Tag vorhanden

Diese Punkte sind für die praktische Demonstration vorgesehen. Sie sind erst erledigt, wenn sie tatsächlich getestet bzw. vorgeführt wurden.
